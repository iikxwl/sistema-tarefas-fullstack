# Sistema de Tarefas Full Stack

Projeto de estudo para praticar integração entre front-end e back-end usando HTML, CSS, JavaScript, Node.js e Express.

## Objetivo

Construir uma aplicação simples de tarefas para entender o fluxo completo de uma aplicação web: interface, eventos, requisições HTTP, rotas e dados.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## Funcionalidades planejadas

- Criar tarefa
- Listar tarefas
- Marcar tarefa como concluída
- Remover tarefa
- Integrar front-end com API
